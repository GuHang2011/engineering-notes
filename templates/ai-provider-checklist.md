## 账号与密钥

- [ ] A、B 两个测试账号分别使用自己的配置，不能读取或修改对方配置。
- [ ] 查询配置仅显示密钥配置状态，不回传完整密钥。
- [ ] 密钥不出现在 URL、浏览器存储、文稿、导出文件或诊断日志中。
- [ ] 更换服务地址时重新确认并提供密钥，不把旧密钥发给新地址。
- [ ] 保存、留空保留、替换、删除、重启后的行为都有验证记录。
- [ ] 加密主密钥持久化与备份恢复已验证，轮换方式明确。

## 网络与费用

- [ ] 仅允许批准的地址、协议和端口，校验 DNS 解析和重定向行为。
- [ ] 内网、回环、元数据地址和携带 URL 凭据的请求被拒绝。
- [ ] 连接失败、超时、401、429 和 5xx 均显示可理解的错误。
- [ ] 并发和输出预算有限制；自动重试不会无限消耗额度。
- [ ] 页面说明哪些数据发送给哪个服务商，测试连接可能产生费用。

地址限制使用本地隔离夹具验证，不向真实内网或云元数据服务发探测请求。

## 办公流程

- [ ] 生成结果可修改，保存、审批和发送仍由用户确认。
- [ ] 失败保留输入和已生成文稿，重试不重复提交业务操作。
- [ ] PPT 输出格式、页数、备注和中文文字均经过检查。
- [ ] PPT 在实际使用的 PowerPoint / WPS 中能编辑，排版没有溢出。
- [ ] 已生成文稿可以重新导出，下载失败不强制再次调用模型。
- [ ] 浏览器草稿按账号区分，支持清除，并提示公用设备上的保存状态。
