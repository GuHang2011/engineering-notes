## 发布前

- [ ] 数据库、文件目录和加密主密钥均有受控备份，记录时间与恢复点。
- [ ] 最近一次隔离恢复演练成功，文件和数据库记录能对应。
- [ ] 数据库变更与旧应用兼容；不兼容时已有单独的数据恢复方案。
- [ ] 默认密码已更换，部署包、前端产物、日志里没有真实密钥。
- [ ] 仅开放必要入口，数据库端口不向终端用户开放。
- [ ] HTTPS 证书、代理路径、分片大小和超时经过目标环境验证。
- [ ] 持久卷、服务账号权限、磁盘空间和监控均可用。

## 发布后

- [ ] 健康检查成功，日志没有持续错误或重启循环。
- [ ] 普通账号能登录、退出；跨账号、跨学院资源访问被拒绝。
- [ ] 用测试文件完成上传、预览、下载和字节校验。
- [ ] 任务提交、审核和公告可见范围符合预期。
- [ ] 群成员能访问文件，移出群后旧入口不能继续发起下载。
- [ ] AI 配置读取不返回密钥，连接测试和失败提示正常。
- [ ] AI 生成保持草稿状态，PPT 能下载并在目标办公软件中打开。
- [ ] 观察约定时间内的错误率、响应分位数、连接池和磁盘增长。

## 恢复演练

在隔离环境恢复，不覆盖现网。记录每一步耗时与失败原因：

1. 恢复匹配版本的应用、数据库、文件和加密主密钥。
2. 验证记录数量、抽样文件摘要和必要的加密数据读取。
3. 使用测试账号重新完成关键业务流程。
4. 对比实际恢复耗时和数据缺口是否满足发布前约定。
5. 删除演练数据或按学校规则保留，并记录负责人确认。
