# 智能工程技术学院首页优化记录（2026-10-26）

本轮针对高质量考核系统首页的信息层级、学院识别和手机排版进行调整。主视觉采用深青色、金铜色点缀、工程网格与芯片电路图形；统一登录页、侧栏、浏览器标题和系统图标中的学院名称。图形为系统设计标识，不是学院官方校徽。

相关代码见[前端精选仓库](https://github.com/GuHang2011/college-archive-system-frontend)，效果见[桌面截图](../screenshots/home-dashboard-desktop-2026-10-26.png)和[手机截图](../screenshots/home-dashboard-mobile-2026-10-26.png)。

## 问题与修复

| 问题 | 处理方式 |
| --- | --- |
| 首页学院识别不足，主要操作缺少明确层级 | 增加学院主题横幅，把归档资料和数据/任务入口放在首屏，按概览、待办、协作工具、公告组织内容。 |
| 全局标题样式覆盖首页横幅背景、边框和字号 | 从通用标题选择器中移除首页横幅；为首页容器设置独立背景与间距。 |
| 管理员有五张指标卡，原四列分隔规则导致边框和排布不一致 | 桌面采用五列，较窄窗口采用三列，手机采用两列并让最后一张卡独占一行；骨架屏使用相同角色布局。 |
| 手机横幅中的日期和状态信息靠近操作按钮 | 增加横幅空间，将状态信息置于底部独立区域，允许换行。 |
| 手机辅助文字过小 | 调整任务提示、快捷入口、公告和页脚字号，并增大主要操作按钮高度。 |
| 学院名称和图标风格不一致 | 统一为“智能工程技术学院高质量考核系统”，将文件上传图标改为芯片/电路图形。 |

管理员首页展示审核、建设任务和在线账号信息；教师首页展示整改和待提交任务入口。页面继续读取已有 dashboard、workspace 和公告接口，不在界面中写入虚构业务数据。

## 相关文件

- `src/views/home/index.vue`：首页布局、数据加载、错误重试、角色入口和响应式样式。
- `src/theme/app.scss`：隔离首页与通用页面标题的样式。
- `src/stores/themeConfig.ts`、`src/App.vue`、`src/utils/other.ts`：学院标题、主题缓存和浏览器标题。
- `src/layout/logo/index.vue`、`src/views/login/index.vue`、`index.html`：侧栏、登录页和页面品牌。
- `public/brand-mark.svg`、`src/assets/logo-mini.svg`：芯片/电路系统标识。

## 本轮验证

在完整本地应用中执行：

```text
npx tsc --noEmit --skipLibCheck
npm run build
node scripts/verify-layout-ui.cjs
```

TypeScript 检查和 Vite 生产构建均成功。TypeScript 命令不等同于 vue-tsc 的 Vue 模板类型检查。

浏览器测试使用 Edge 148.0.3967.83 和模拟 API：

- 登录页：1440、390、320 像素宽度及 844 像素横屏的资源、标签和布局检查。
- 登录交互：空字段校验、错误密码提示、重试和回车登录。
- 个人资料：加载骨架、加载失败与重新加载。
- 首页、账号管理、统计、个人中心、AI 配置：1440 与 390 像素的布局和容器横向溢出检查。
- 测试未捕获到页面脚本异常或 404 资源。
- 人工查看桌面和手机首页截图，并修正了手机横幅状态区位置。

截图使用合成账号和模拟数据，展示视口中的界面。它们不是学校生产数据，也不是页面所有内容的完整长截图。本轮没有重新验收真实宝塔服务器、完整业务接口或所有浏览器内核；教师角色、任务长标题和接口故障等场景没有在本轮单独新增浏览器用例。
